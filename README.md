# Heart Failure Mortality Prediction

A Machine Learning based web application for predicting the risk of mortality in heart failure patients using patient-related clinical features.

## 🏫 Institution

**GL Bajaj Institute of Technology and Management**  
Greater Noida, Uttar Pradesh

## 📌 Project Overview

Heart failure is a serious medical condition that requires proper monitoring and risk assessment.

This project uses a Machine Learning model to provide a prediction based on the input clinical parameters. The model is integrated with a Flask web application that provides a simple and user-friendly interface.

## 🚀 Features

- User-friendly web interface
- Heart failure mortality prediction
- Machine Learning based prediction
- Flask backend
- Pre-trained Machine Learning model
- Simple and responsive design
